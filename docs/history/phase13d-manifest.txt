CREATED (8)
-----------
src/lib/db/models/Global.ts
  Native Mongoose model mapping onto Payload's existing `globals`
  MongoDB collection (discriminated by `globalType`).

src/lib/repositories/GlobalsRepository.ts
  `GlobalsRepository` interface + `MongoGlobalsRepository` — read-only
  native repository for Header/Footer/Settings.

src/lib/repositories/adapters/globalsStorefrontAdapter.ts
  Pure functions mapping native Header/Footer/Settings + resolved nav
  relations onto the exact payload-types.ts shapes the storefront reads.

src/app/_api/fetchGlobalsNative.ts
  Testable orchestration (buildStorefrontHeader/Footer/Settings) plus
  DB-wired fetchHeaderNative/fetchFooterNative/fetchSettingsNative/
  fetchGlobalsNative, mirroring fetchCategoriesNative.ts's pattern.

src/app/_components/ErrorBoundary/index.tsx
  Minimal client-side React error boundary. Wraps HeaderComponent /
  FooterComponent so a render-phase crash inside them degrades to
  rendering nothing instead of crashing the whole page.

tests/fakes/FakeGlobalsRepository.ts
  In-memory fake implementing GlobalsRepository, plus
  buildTestHeader/Footer/Settings builders, for DB-free unit tests.

tests/globalsStorefrontAdapter.test.ts
  10 tests covering toStorefrontHeader/Footer/Settings (reference links,
  custom-url links, missing/unresolvable page or media references, null
  copyright, empty navItems).

tests/fetchGlobalsNative.test.ts
  8 tests covering buildStorefrontHeader/Footer/Settings orchestration
  against fake repositories: successful resolution, "no global exists
  yet" -> null (not a throw), and dangling page/media references.

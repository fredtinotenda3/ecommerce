# Terro Technology — image asset log and polish prompts

This is the asset-by-asset record the rebrand brief asked for: what every
supplied file was examined for, what was cropped or cleaned up and why,
what was excluded and why, and — for the handful of assets that would
benefit from real retouching before launch — a prompt to hand to a
designer or an external AI image tool. Nothing in this document was
generated by an image model; every "final" asset in `public/media/` and
`public/brand/` is a crop, mask or composite built directly from a file
Terro supplied, using PIL/ffmpeg in this environment. Where no supplied
asset was suitable, the gap is recorded here and the actual generation
prompt lives in `docs/image-generation-prompts.md` instead.

Terro supplied 24 JPEGs and one MP4 (`terro-video.mp4`). All 25 files were
opened and inspected — dimensions read from the file, corners scanned for
watermarks, and content evaluated against Zimbabwe retail reality — before
any placement decision below was made.

## Excluded entirely

**`laptop2.jpeg`** — an HP EliteBook lifestyle photograph. A contrast-enhanced
crop of its bottom-left corner shows a faint, semi-transparent third-party
watermark, consistent with a tech-review site's own photography rather than
anything Terro produced or licensed. All 21 other JPEGs' four corners were
then batch-scanned the same way; none of them showed anything similar. This
is the one asset in the supplied set this project will not use, in whole or
cropped, anywhere in the storefront.

## Reviewed, not used

These were opened, measured and considered, and none of them is a mistake
by omission — each was set aside for a specific reason, not overlooked:

- **`cracked-phone-case.jpeg`**, **`laptop-covers.jpeg`** / **`laptops-covers.jpeg`**
  (the same "Laptop Covers — Fixing & Replacement" flyer, twice, at two
  export sizes) — service-marketing graphics whose entire frame is
  Terro's own price-free promotional text and stacked stock renders of
  laptop shells; no region of any of them crops down to a clean, text-free
  photograph. If Terro later wants a dedicated "phone back covers" or
  "laptop shell replacement" accessory listing, these are the flyers to
  ask them for real photos to replace.
- **`laptop.jpeg`** — a clean, watermark-free stock-style photograph of a
  laptop keyboard with water droplets on it (illustrating liquid-damage
  repair). Genuinely usable, and it was seriously considered for the
  `warranty` page — but `warranty-repair-bench.jpg` and
  `about-repair-detail.jpg` already cover that page and the `about` page
  with real repair-bench photography, and adding a third repair image site-
  wide would be more than the copy needs. Kept in reserve; a good candidate
  if a future "liquid damage" callout wants its own image.
- **`latest-laptops-discover.jpeg`** — a marketing collage (a stock model
  plus a fanned arrangement of several closed laptops showing Asus ROG, HP,
  Acer and Lenovo branding). Not used: it implies a specific multi-brand

  that category's product-photo gap is instead being closed.
- **`macbook.jpeg`** — an illustrated "before/after" graphic (cracked
  screen vs. a normal one) captioned "Macbook Screens, Batteries & Repairs."
  Not a photograph. Not used, for the same reason as `laptop.jpeg`: the
  warranty and about pages already carry real repair photography.
- **`phone-service.jpeg`** — gloved hands holding phones with an
  illustrated crack overlay, captioned "Don't let a broken phone ruin your

- **`preloved-smart-phones.jpeg`** — see the `preloved-iphone-x-64gb.jpg`
  row above; partially used already.
- **`summer-deals.jpeg`**, **`winter-deals.jpeg`** — seasonal promotional

## Logo component: a deliberate simplification, not an oversight

The header and footer no longer render a wordmark image at all —
`_components/Logo` draws `terro-icon.png` for the mark and sets "Terro" /
"Technology" as live text, styled with the theme's own ink colour. Tech
Haven's logo needed an "auto" variant that swapped between two rendered
image files for light/dark mode; Terro's real mark is a two-colour icon
that reads fine on either background on its own, and live text is sharper
than a JPEG-sourced wordmark and never needs a second file. This is why
`terro-logo-lockup.png` (the full mark-plus-wordmark image) exists on disk
but nothing currently references it.

## Known limitation: the favicon is a raster wrapped in SVG, not a true vector trace

`potrace` (or an equivalent vector-tracing tool) was not available in this
environment, and hand-tracing the shield shape's curves node-by-node was
judged too likely to drift from the real mark under the time available.
`favicon.svg` is therefore an SVG document that embeds the same PNG as a
base64 data URI — it scales as a raster, not as true vector paths. It is
correct and displays properly everywhere a favicon is used; a true vector
trace would only matter if Terro needs the mark at very large sizes (e.g.
vehicle signage) or wants to hand-edit it directly, which is a design-tool
task, not a code task.

## Polish prompts for an external design tool

Nothing here is required before launch — every asset above already ships
clean. These are optional upgrades, for a human designer or an external AI
image tool to execute, if Terro wants to invest further before or after
going live. None of them should be run as an automated step in this
codebase; hand the prompt (and the named source crop) to whichever tool or
person will do the retouching, and swap the result into the same filename
under `public/media/` or `public/brand/` once approved.

1. **`terro-icon.png` — true vector redraw.**
   > Redraw this shield-and-arrow logo mark as a clean vector illustration (SVG), preserving its exact proportions, the red-and-blue two-tone split, and the sharp geometric point at the base. Output as scalable vector paths, not a traced raster. Reference image: public/brand/terro-icon.png.

2. **`hero-phones.png` — professional cutout and relight.**
   > Take this three-phone product photo (Huawei, Samsung, iPhone) and produce a clean, professionally masked cutout with consistent studio lighting across all three devices, keeping the same camera angle and phone order. Preserve exact phone models and colours — do not restyle or replace any device. Output on a transparent background at a higher native resolution than the 460×280 source. Reference image: public/brand/hero-phones.png (sourced from boxed-smart-phones.jpeg).

3. **`warranty-repair-bench.jpg` — colour-grade consistency pass.**
   > Colour-grade this repair-bench photo to sit visually alongside the rest of a cool, Deep-Electric-Cobalt-toned website (hex family #0755C9 / #123E9B / #1769E8 / #082B73) — a light, neutral cool-white balance rather than the warm indoor tone it currently has. Do not alter, add, or remove any object in the frame. Reference image: public/media/warranty-repair-bench.jpg (sourced from computer-fix.jpeg).

Everything else listed as "used" above is considered launch-ready without
further retouching.

PHASE 13V MANIFEST
===================
Modified:
  src/app/_components/Media/types.ts
    - Props.resource changed from `string | payload-types.ts Media` to
      `string | StorefrontMediaItem` (src/app/_types/storefront.ts).
    - Dropped the `payload-types.ts` import from this file entirely.
    - No other Props fields changed.

  src/app/_types/storefront.ts
    - Added StorefrontHeroMedia view model
      (StorefrontMediaItem & { caption?: StorefrontRichText }), for the
      two callers (HighImpactHero, MediaBlock) that read `.caption`
      directly off a populated media object in addition to forwarding it
      to <Media resource={...} />.
    - StorefrontProductHeroView's local doc comment updated: ProductHero's
      local `meta.image` override now documented as `StorefrontMediaItem`
      instead of the full payload-types.ts `Media` (no behavior/shape
      change to StorefrontProductHeroView itself — meta.image there still
      stays at StorefrontMediaRef, unchanged from Phase 13U).
    - Updated two now-stale file-level/interface doc comments (the
      original PHASE 13L note about `media` needing the full Media shape,
      and StorefrontMediaLayoutBlock's doc comment about MediaBlock's
      `media` field) to reflect that Media/types.ts's `resource` prop is
      no longer full-Media-only, per this phase.
    - Updated StorefrontMediaItem's trailing doc comment (previously
      describing the Phase 13N follow-up as not-yet-done) to record that
      Phase 13V is that follow-up.
    - No new interfaces' shapes affect any adapter/fetch helper; no
      change to StorefrontMediaItem's own fields.

  src/app/_heros/Product/index.tsx (ProductHero)
    - Dropped the `payload-types.ts` import entirely (no longer needs
      `Media` — see below).
    - Local `ProductHeroProduct` type's `meta.image` changed from
      `string | MediaType` (payload-types.ts `Media`) to
      `string | StorefrontMediaItem`.
    - No JSX/rendering/behavior changes.

  src/app/_heros/HighImpact/index.tsx (HighImpactHero)
    - Dropped the `payload-types.ts` import entirely.
    - `Props.media` changed from `string | MediaType` to
      `string | StorefrontHeroMedia` (needs `.caption`, which this
      component reads directly).
    - No JSX/rendering/behavior changes.

  src/app/_heros/MediumImpact/index.tsx (MediumImpactHero)
    - Dropped the `payload-types.ts` import entirely.
    - `Props.media` changed from `string | MediaType` to
      `string | StorefrontMediaItem` (this component never reads
      `.caption`, so the plainer view model suffices).
    - No JSX/rendering/behavior changes.

  src/app/_blocks/MediaBlock/index.tsx (MediaBlock)
    - Dropped the `payload-types.ts` import entirely.
    - `Props.media` changed from `string | MediaType` to
      `string | StorefrontHeroMedia` (this component reads `media.caption`
      directly).
    - No JSX/rendering/behavior changes.
